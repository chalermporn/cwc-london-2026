สร้าง AI agent ด้วย Claude บน Microsoft Foundry (เวิร์กชอป cupcake agent)

Build AI agents using Claude in Microsoft Foundry

ผู้พูด: Marlene Mungami (senior developer advocate, Microsoft); Liam Hampton (Microsoft (ผู้ร่วมเวิร์กชอป)); Chris Snoring (ผู้ร่วมเวิร์กชอป (ไม่ระบุตำแหน่ง))

เหมาะกับ: นักพัฒนาที่ใช้ Azure/Microsoft อยู่และอยากใช้ Claude สร้าง agent บน Foundry ต้องรู้ Python เบื้องต้น

เวิร์กชอปบน Microsoft Foundry: deploy Claude Sonnet 4.6, ลองใน playground, ต่อเข้า VS Code ด้วย endpoint+key, สร้าง cupcake agent ด้วย Microsoft Agent Framework แล้วเสียบ MCP server ของร้านให้ดึงข้อมูล คำสั่ง prompt และ banner

A Microsoft Foundry workshop: use Claude Sonnet 4.6 in the playground, wire endpoint and key into VS Code, build an agent with Microsoft Agent Framework, and give it a cupcake-store MCP server for tools and prompts.

ประเด็นสำคัญ

  1. ผู้พูดมองว่าอุตสาหกรรมเปลี่ยนจาก single-turn ไปเป็น agentic system ซึ่งมีโจทย์ใหม่ 3 ข้อ คือ multi-step reasoning บน long context, ความน่าเชื่อถือ/observability/ความปลอดภัย และการเชื่อมต่อ tool กับแหล่งข้อมูล
  2. Microsoft Foundry ถูกแนะนำเป็นแพลตฟอร์มรวมสร้าง AI application และ agent ประกอบด้วย models (รวม Claude), agent service, tools/integrations และ ML services เช่น fine-tuning
  3. ผู้พูดบอกว่ามี connector และ MCP tool built-in กว่า 1,400 ตัว (เช่น SAP, ServiceNow) พร้อมฟีเจอร์ enterprise: security, observability, governance, ผสานกับ Defender, Purview, Entra ID
  4. เหตุผลที่ใช้ Claude บน Foundry ตามผู้พูด 4 ข้อ: reasoning ระดับดีสุดสำหรับ agent, สร้าง/orchestrate agent และให้ tool ในแพลตฟอร์มเดียว, enterprise features, และวงจร prototype ถึง production เร็วด้วย evaluation/observability/monitoring ในตัว
  5. workshop ทำบน Skillable VM ผ่าน aka.ms/cloudworkshop โจทย์คือร้านคัพเค้ก Sparkles ที่ลูกค้าเยอะเกินคนรับออเดอร์ จึงสร้าง agent มารับออเดอร์
  6. ใน Foundry เลือก Build > Models เห็น Claude Sonnet 4.6 เปิด playground แก้ system prompt ลองคุยได้ ใช้เทียบโมเดลและ prompt
  7. ดึง target URI กับ API key จากแท็บ details ใส่ไฟล์ .env ใน VS Code โดยต้องลบ v1/messages ท้าย endpoint ให้ลงท้ายด้วย anthropic แล้วตั้ง model เป็น Claude Sonnet 4.6
  8. สร้าง agent ด้วย Microsoft Agent Framework (open source ของ Microsoft, Python และอาจมี TypeScript) แล้วต่อ cupcake store MCP server เป็น tool ได้ข้อมูลรสชาติจริง พร้อมดึง prompt (agent instructions กับ welcome banner) จาก MCP server ด้วย

ลำดับขั้นที่ทำในคลิป

  1. เปิด aka.ms/cloudworkshop กด Launch เพื่อเปิด VM บน Skillable (คลิกกล่องเขียวเพื่อกรอกค่าอัตโนมัติ)
  2. เปิด Edge > Microsoft Foundry ล็อกอินด้วย username/password ที่ให้มา เลือก project
  3. Start building > Build > Models ดู Claude Sonnet 4.6 เปิด playground ลองคุยและเปลี่ยน system prompt (เช่น sentient cupcake ตอบด้วยมุกฟรอสติ้ง)
  4. ไปแท็บ details คัดลอก target URI และ API key
  5. เปิด VS Code แก้ .env: ใส่ endpoint (ตัด v1/messages ให้ลงท้ายด้วย anthropic), API key และชื่อ model Claude Sonnet 4.6
  6. เปิด agent.py วางโค้ด Microsoft Agent Framework: import agent, สร้าง chat client (อ่านค่า deployment/key/endpoint จาก .env), นิยาม cupcake agent แล้วรันตามคำสั่งใน terminal
  7. วางบล็อกโค้ดต่อ cupcake store MCP server ผ่าน URL ส่งเป็น tool ให้ agent (ต้อง save ไฟล์แล้วรันใหม่) ถามรสวันนี้
  8. โหลด instructions และ welcome banner เป็น prompt จาก MCP server
  9. คุยกับ agent: สร้าง customer ID ใหม่ (ชื่อ นามสกุล เมือง) เลือกรส red velvet
  10. อ่าน voucher 6 ตัวอักษรจากแดชบอร์ดหน้าห้อง ใส่ให้ agent รอออเดอร์ขึ้น ready for pickup และรับคัพเค้ก

ตัวเลข / ข้อเท็จจริงที่ผู้พูดบอก

ตามที่ผู้พูดอ้างในคลิป ไม่ได้ยืนยันกับแหล่งอื่น

  • Foundry มี built-in connectors และ MCP tools มากกว่า 1,400 ตัว ตามที่ผู้พูดบอก
  • ผู้พูดบอกว่า Opus 4.7 เป็น "daily driver" ของตน
  • โมเดลใน workshop: Claude Sonnet 4.6
  • รสคัพเค้กจาก MCP: classic vanilla, lemon sponge, red velvet, chocolate
  • เทมเพลต endpoint ต้องตัด v1/messages ออก ให้ลงท้าย anthropic
  • ลิงก์เวิร์กชอป: aka.ms/cloudworkshop (ตามที่พูด)

ประโยคเด่น (ต้นฉบับ)

“you can't just rely on the models getting better”

จะพึ่งแค่โมเดลที่เก่งขึ้นอย่างเดียวไม่ได้

“MCP is Model Context Protocol, and this is an open standard for letting AI agents talk to external systems”

MCP คือ Model Context Protocol มาตรฐานเปิดให้ agent คุยกับระบบภายนอก

“a good example of why it needs the MCP server because it needs to have that context available for it to be able to know which flavors are available”

ตัวอย่างว่าทำไมต้องมี MCP server: agent ต้องมี context นั้นจึงรู้ว่ามีรสอะไรบ้าง

สิ่งที่นำไปทำต่อ

  • จะใช้ Claude บน Foundry ต้องมี endpoint (ตัด v1/messages), API key และชื่อ deployment
  • ใช้ playground ทดลองโมเดลกับ system prompt ก่อนเขียนโค้ด
  • MCP server ให้ได้ทั้ง tools, prompts, resources ใช้ส่ง persona/banner ของ agent ได้
  • Microsoft Agent Framework เป็นทางเริ่มสร้าง agent บน Foundry แบบ open source
  • ทำเวิร์กชอปซ้ำที่บ้านได้ โค้ดและเนื้อหาจะแชร์ (ผู้พูดบอก) และมี free Azure credits
