ใช้ Claude บน AWS: ตั้งแต่ Claude Code บน Bedrock ถึง agent orchestration

AI with Claude on AWS: From code to orchestration

ผู้พูด: Antonio Rodriguez (Amazon Web Services (นักพัฒนา/ผู้บรรยายเวิร์กชอป))

เหมาะกับ: ทีมที่อยู่บน AWS หรืองาน regulated ที่อยากใช้ Claude Code ผ่าน Bedrock รู้จัก Claude Code มาบ้างแล้ว

ภาพรวมความร่วมมือ Anthropic-AWS และ 3 ทางใช้ Claude บน AWS (Bedrock, Claude platform on AWS, Claude Desktop/Enterprise) ตามด้วยเวิร์กชอป Claude Code บน Bedrock 3 โมดูลบนโปรเจกต์ Excalidraw ที่ AWS แจก account ให้ทดลอง

Overview of the Anthropic-AWS partnership and three ways to use Claude on AWS, followed by a three-module Claude Code on Bedrock workshop built around an Excalidraw repo.

ประเด็นสำคัญ

  1. ผู้พูดเล่าว่า Amazon ลงทุนหลายพันล้านดอลลาร์ใน Anthropic และเป็น primary cloud provider โดย Anthropic ผูกพันใช้งานบน AWS มากกว่า 100 พันล้าน (หน่วยตามที่ได้ยิน) เช่น Project Rainier และชิป Trainium รุ่น 3
  2. จุดขายของ Bedrock 3 ข้อ: ฟีเจอร์ครบ (fine-tune รวม Haiku, evaluation, prompt optimization, distillation, knowledge bases, guardrails, automated reasoning checks), ความปลอดภัย (ข้อมูลอยู่ใน AWS boundary, PrivateLink, zero operator access) และ scalability กับการเลือก region เช่น London หรือ EU เพื่อ GDPR
  3. ผู้พูดระบุว่าไม่มีใครจาก Amazon หรือ Anthropic เข้าถึง instance ได้ และข้อมูลไม่ถูกใช้เทรนโมเดล
  4. ข้อดีอื่น: data sovereignty, ใบเรียกเก็บเงินรวม, observability ผ่าน CloudWatch/CloudTrail, SLA, auth ผสาน SSO/OAuth/IAM กับ Entra ID หรือ Okta, compliance เช่น FedRAMP กับ HIPAA
  5. สำหรับ agent มี Amazon Bedrock AgentCore สำหรับ host agent อย่างปลอดภัย ใช้ได้กับ framework เปิด เช่น LangChain, CrewAI และ Claude Agent SDK
  6. ใช้ Claude บน AWS ได้ 3 ทาง: (1) Bedrock โดยตรง ล่าสุดเพิ่ม Opus 4.7 และ Messages API (2) Claude platform on AWS ที่ GA เมื่อไม่กี่วันก่อน เป็น gateway ส่งคำขอไป Anthropic ได้ feature parity บิลและ access control อยู่ AWS (3) Claude Desktop/Claude Code ผ่าน Claude Enterprise ใน AWS Marketplace หรือ 3P setup ที่ชี้ไป Bedrock
  7. เวิร์กชอป Introduction to Claude Code on AWS ใช้ repo Excalidraw: โมดูล 1 ตั้งค่าพื้นฐาน, โมดูล 2 context + Playwright MCP จับ screenshot ไดอะแกรม + Git workflows, โมดูล 3 sub agents, plugins, custom skills, hooks และ advanced config และมีเวิร์กชอปขั้นสูงเรื่อง team standards, cost control, dashboards, ROI และ Agent SDK บน AgentCore
  8. ปิดด้วยตัวอย่างตั้งค่า Claude Code ชี้ Bedrock (region, default model, ลด token, rate limit, telemetry) ซึ่งสั่งให้ Claude ตั้งค่าตัวเองหรือทำมือผ่าน settings ก็ได้

ลำดับขั้นที่ทำในคลิป

  1. เข้า join.thatworkshop.aws ใส่ access code ที่แสดงบนจอ ยอมรับ terms แล้วกด join event (ห้ามอัปโหลดข้อมูลลับหรือข้อมูลส่วนบุคคล)
  2. เปิด URL ที่ได้ไปยัง terminal และ VS Code UI ใน environment ที่ AWS เตรียมให้
  3. โมดูล 1: ใช้ Claude Code บน AWS ตั้งค่าและชี้ไปที่ repo Excalidraw
  4. โมดูล 2: จัดการ context ใช้ Playwright MCP ถ่าย screenshot ไดอะแกรมแล้วให้ Claude แก้อัตโนมัติ และลอง Git workflows
  5. โมดูล 3: sub agents, plugins, custom skills, hooks และ advanced configuration
  6. ทางเลือก: รันบนเครื่องตัวเองโดยตั้ง Claude Code ชี้ Bedrock หรือใช้ Claude Desktop ชี้ Bedrock
  7. ตั้งค่าเอง: กำหนด region ของ Bedrock, default model, พารามิเตอร์ลด token และ rate limit, เปิด telemetry, ปิด login prompt/onboarding message

ตามที่ผู้พูดอ้างในคลิป ไม่ได้ยืนยันกับแหล่งอื่น

  • Anthropic ผูกพันการใช้งานบน AWS "more than 100 billion" ตามที่ได้ยิน (หน่วยไม่ชัด)
  • Trainium รุ่นที่ 3 ที่ AWS สร้างขึ้นสำหรับ Claude ตามที่ผู้พูดบอก
  • Bedrock เพิ่ม Opus 4.7 และรองรับ Messages API
  • Claude platform on AWS เป็น GA "since a few days ago"
  • ผู้พูดเริ่มทำงานกับ Anthropic เมื่อมากกว่า 3 ปีก่อน ตอน Claude 2 เปิดตัว
  • ลิงก์เข้า account เวิร์กชอป: join.thatworkshop.aws (ตามที่ได้ยิน)

  • ถ้าองค์กรอยู่บน AWS ลองใช้ Claude Code ผ่าน Bedrock เพื่อให้ข้อมูลอยู่ใน boundary และรวมบิล
