Agent Battle: แข่งสร้าง agent ขุดเพชรใน Minecraft ด้วย Managed Agents

Agent Battle: Mine the most diamonds in 45 minutes

ผู้พูด: Ben (Applied AI team, Anthropic); Jeff (Applied AI team, Anthropic)

เหมาะกับ: คนที่อยากเห็นตัวอย่างการจัด eval แบบแข่งขัน และการปรับ system prompt, model, skill, MCP ของ managed agent เพื่อ hill climb

เวิร์กชอปแข่งขันสั้นๆ ที่ผู้เข้าร่วมแต่ง Claude managed agent ให้เล่น Minecraft ขุดเพชร ผ่าน Mineflayer bot กับ MCP tools แล้วแข่งกันบน leaderboard ในเวลา 35 นาที ตัดสินที่จำนวนเพชร และตัดเสมอด้วยอัตราเพชรต่อ token ผลที่ได้ยินคือมีคนขุดได้ 19 เพชรหลายคน และมีคนทำเกิน 19 ก่อนหมดเวลา

A short in-room competition where participants tune a Claude managed agent to mine diamonds in a Minecraft clone via a Mineflayer bot; ranked by diamonds, tie-broken by token efficiency; 19 diamonds was the common top score and one run beat it.

ประเด็นสำคัญ

  1. ผู้จัดคือ Ben กับ Jeff จาก Applied AI ที่ Anthropic เป้าหมาย 3 อย่าง: เรียนรู้การสร้างและ deploy managed agent ที่โฮสต์บนโครงสร้างของ Anthropic, เข้าใจผลของ agent configuration (system prompt, model string, skills, MCP) และฝึก hill climb บน evals
  2. กติกา: จับเวลาราว 35 นาทีให้สร้างและทดลอง ส่งกี่รอบก็ได้แต่นับรอบที่ดีที่สุดเพียงรอบเดียวต่อคน แต่ละรอบ agent ขุดเพชร 5 นาที หยุดกลางคันได้ด้วย Ctrl-C
  3. มี eval set ที่รันราว 1 นาทีไว้ให้ปรับ agent อย่างรวดเร็ว ผู้ชนะคือคนที่ได้เพชรมากสุดเมื่อครบเวลา
  4. กติกาตัดเสมอใช้ token efficiency คืออัตราเพชรต่อ token ผู้จัดย้ำว่าไม่ใช่แค่ขุดให้ได้มากสุด และไม่ควรโยนโมเดลหนักสุดใส่ แต่ต้องปรับ system prompt ให้แหลม
  5. harness: Minecraft clone ที่เชื่อมกับ Mineflayer bot ไม่ใช้ภาพ มี MCP tools เช่น mine block, jump, go near; ทุกคนเริ่มจาก seed และ start kit เดียวกัน; แก้ไขที่ myagent.py ในรีโป /agentbattle ได้แก่ model, system prompt (เริ่มต้นว่างเปล่า), skill ที่ Anthropic ส่งมาให้หรือใส่เอง และมี MCP server ให้ปรับ
  6. ในรีโปมี Claude Code skill ช่วย setup และมีปัญหา Cloudflare จาก Wi-Fi งานที่คนเข้าเยอะ ผู้จัดแปะคำสั่งแก้ที่ได้ผลกับอย่างน้อยหนึ่งคน
  7. ระหว่างแข่ง: เริ่มมีรอบแรกที่ได้ 10, เหลือราว 5 นาทีเสมอกันสามทาง และคนแรกแสดง 0 token ซึ่งน่าสงสัย ผู้จัดบอกว่า 19 น่าจะเป็นเพดานของที่ทำได้ แต่ก่อนหมดเวลา 1 นาที 20 วินาทีมีคนทำเกิน 19
  8. ผลสรุป: ผู้ชนะชัดเจนหนึ่งคน คนที่ขุดได้ 19 ให้มาหา Ben กับ Jeff และเนื่องจากอันดับสองแสดง 0 token ผู้จัดยังตัดสินอันดับสองกับสามไม่ได้ จึงเรียกอันดับ 1 ถึง 5 ขึ้นมา โดยยังไม่ประกาศรางวัล

ลำดับขั้นที่ทำในคลิป

  1. เข้ารีโป /agentbattle แล้วเปิดไฟล์ myagent.py
  2. ปรับ model, system prompt (เริ่มต้นว่าง), skill ที่ให้มา หรือ skill ของตัวเอง และ MCP server ถ้าต้องการ
  3. ใช้ Claude Code skill ในรีโปช่วย setup ถ้าติดปัญหา
  4. รัน eval ราว 1 นาทีเพื่อ iterate เร็ว แล้วส่ง run เต็ม 5 นาที (หยุดด้วย Ctrl-C ได้)
  5. ดู leaderboard และแชตที่ agent คุยกัน; ส่งได้หลายรอบแต่นับรอบที่ดีที่สุดรอบเดียว
  6. เมื่อหมดเวลาประกาศผล ตัดเสมอด้วย diamonds-to-tokens ratio

ตัวเลข / ข้อเท็จจริงที่ผู้พูดบอก

ตามที่ผู้พูดอ้างในคลิป ไม่ได้ยืนยันกับแหล่งอื่น

  • เวลาแข่งราว 35 นาที (ชื่อคลิปบอก 45 นาที)
  • แต่ละรอบ agent ขุด 5 นาที; eval set รันราว 1 นาที
  • รอบแรกที่เห็นบน leaderboard ได้ 10 เพชร
  • 19 เพชร ถูกเรียกว่าน่าจะเป็นเพดาน และมีคนทำเกิน 19 เมื่อเหลือ 1 นาที 20 วินาที (ไม่ได้ยินตัวเลขสุดท้าย)
  • ตัดเสมอด้วยอัตราเพชรต่อ token

สิ่งที่นำไปทำต่อ

  • ตั้ง eval ที่เร็ว (ราว 1 นาที) ไว้ก่อน แล้ว hill climb ที่ system prompt/model/skill ทีละอย่าง
  • ตั้งเมตริกตัดสินที่รวมประสิทธิภาพ (เพชรต่อ token) ไม่ใช่แค่ผลลัพธ์ดิบ เพื่อไม่ให้ชนะด้วยการโยนโมเดลหนักสุด
  • ใช้ seed และ start kit เดียวกันเพื่อให้เทียบ config ได้เป็นธรรม
  • ตรวจค่า token ที่ผิดปกติ (เช่น 0 token) ก่อนเชื่อผล leaderboard
