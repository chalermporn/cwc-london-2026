Claude Code มีอะไรใหม่: remote control, auto mode, routines, agent view และอื่น ๆ

What's new in Claude Code

ผู้พูด: Ralph (technical staff ที่ Anthropic (Whisper เขียนเป็น 'Entropic') ทำงานกับ partner และลูกค้าทั่วยุโรป)

เหมาะกับ: คนใช้ Claude Code อยู่แล้วและอยากตามฟีเจอร์ใหม่ รวมทั้งทีมที่ดูแลการ deploy ระดับองค์กร

Ralph สรุปฟีเจอร์ Claude Code ที่ปล่อยช่วงไม่กี่เดือนล่าสุดใน 2 หมวด คือ developer experience (remote control, full screen UI ไม่กระพริบ, desktop app ใหม่) และ autonomy (auto mode, worktrees, auto memory, code review, routines, agent view) พร้อมเดโมสดหลายอัน

Ralph walks through recent Claude Code features in two groups, developer experience and autonomy, with live demos of remote control, full-screen TUI, the desktop app, routines and agent view.

ประเด็นสำคัญ

  1. Remote control: เริ่ม session บนเครื่อง แล้วคุมต่อจากแอป Claude บนมือถือหรือเบราว์เซอร์ได้ ใช้คำสั่ง remote control ได้เลย มี notification เมื่อ Claude ต้องการ input และตั้งใน settings.json ให้เปิดตลอดได้
  2. Flicker-free full screen UI: โหมดใหม่ virtualize scrollback ของ terminal เรนเดอร์เฉพาะส่วนที่เห็น ทำให้ไม่กระพริบและ memory ไม่โตตามความยาว session ยังคลิกขยายข้อความ/ปุ่มและกลับลงล่างสุดได้ เปิดด้วยคำสั่ง tui กับพารามิเตอร์ fullscreen และตั้งเป็นค่าเริ่มต้นได้
  3. Desktop app ปรับ UI ใหม่หมด: sidebar จัดกลุ่ม session ตามโปรเจกต์/repo, ดู plan แล้วคอมเมนต์ส่งกลับให้ Claude แก้, ดู diff ของ PR แล้วคอมเมนต์ถามรายบรรทัด, มี GitHub integration และดูไฟล์ทั้งโปรเจกต์ได้
  4. Auto mode: แทนที่จะถามสิทธิ์ทุกครั้ง ใช้ classifier ตรวจ 2 อย่างคือการกระทำนั้น destructive ไหม และดูเหมือน prompt injection ไหม ถ้าผ่านก็ทำต่อ ถ้าไม่ผ่านจะหาทางอื่นก่อน แล้วค่อยมาถามคนเป็นทางสุดท้าย
  5. Worktrees: รองรับแบบ native ใช้ claude --worktree เพื่อให้หลาย session ทำงานใน repo เดียวกันโดยไม่ชนไฟล์กัน ขอให้ Claude สร้างระหว่าง session ก็ได้ และ desktop app มี flag ให้
  6. Auto memory: Claude จดโน้ตเองระหว่างทำงาน (coding style, ตัวเลือกสถาปัตยกรรม, debugging insight) เก็บใน memory.md ที่เป็น index สั้น ๆ ชี้ไปไฟล์ memory รายเรื่อง โหลดทีละส่วนแบบ progressive discovery แชร์ข้าม worktree ของโปรเจกต์ ไม่ออกจากเครื่อง และตรวจได้ด้วย /memory
  7. Code review อัตโนมัติ: หลาย agent ตรวจคนละด้าน (error, bug, vulnerability, logic) ในเฟสแรก แล้วเฟสสองตรวจ findings เทียบโค้ดจริงว่าจริงหรือไม่ ใช้ผ่าน GitHub app กับทุก PR หรือสั่งเองด้วย /ultra-review
  8. Routines (research preview, ปล่อยต้นเดือนนี้): สร้าง session อัตโนมัติจาก schedule, API call หรือ GitHub event รันบน cloud โดยไม่ต้องเปิดเครื่อง เดโมคือ routine เช็ค repo ทุก 08:00 กับ 16:00 และ routine ที่ trigger เมื่อมี issue ใหม่/PR ใหม่
  9. Agent view (public preview): เริ่มด้วย claude agents เห็นทุก session จัดกลุ่มตามสถานะ รันเบื้องหลังได้ กด enter เข้า session หรือกด space ส่ง prompt เข้า session โดยไม่ต้องเข้าไป
  10. สำหรับองค์กร: ปรับปรุงการรองรับ Windows, wizard สำหรับ deploy บน Google Cloud Platform และ AWS, native binaries ให้ติดตั้งผ่าน governance pipeline และแหล่งตามข่าว: @ClaudeDevs, What's New ใน docs, changelog, newsletter

ลำดับขั้นที่ทำในคลิป

  1. Remote control: พิมพ์ remote control ใน session บนเครื่อง ได้ session บนเว็บและมือถือ ลองส่ง prompt ให้ rename session แล้วสลับไปมา
  2. Full screen TUI: ใช้ tui กับพารามิเตอร์ fullscreen แล้วสั่งให้เขียนไฟล์ สังเกตการคลิกขยายข้อความและปุ่มกลับลงล่างสุด
  3. Desktop app: จัดกลุ่ม session ตามโปรเจกต์ ดู plan ใส่คอมเมนต์ ดู diff แล้วถามรายบรรทัด
  4. Routines: เข้าปุ่ม Routines ใน desktop เลือก remote environment ตั้งชื่อ prompt เลือก repo เลือก GitHub event (issue opened) แล้วสร้าง issue ทดสอบดู routine ถูก trigger ด้วย webhook
  5. Agent view: เริ่มด้วย claude agents สั่งงานหลายอันขนาน เข้า session ด้วย enter หรือส่ง prompt ด้วย space

ตัวเลข / ข้อเท็จจริงที่ผู้พูดบอก

ตามที่ผู้พูดอ้างในคลิป ไม่ได้ยืนยันกับแหล่งอื่น

  • รายการฟีเจอร์ที่ผู้พูดไล่ (ตามลำดับ): 1) remote control 2) flicker-free full screen TUI 3) desktop app UI refresh 4) auto mode 5) worktrees 6) auto memory 7) automated code review (/ultra-review) 8) routines 9) agent view
  • คำสั่ง/แฟลกที่ปรากฏ: remote control, tui + fullscreen, claude --worktree, /memory, /ultra-review, claude agents (agent view)
  • สถานะรุ่น: routines = research preview (ปล่อยต้นเดือน), agent view = public preview
  • เดโม routine: รันทุกวันเวลา 8:00 AM และ 4:00 PM ตรวจ commit และ issue ใหม่ของ public repo
  • Auto mode classifier ตรวจ 2 อย่าง: destructive หรือไม่ และเข้าข่าย prompt injection หรือไม่
  • Code review แบบ multi-agent, 2 เฟส; ผู้พูดบอกว่า error ที่คนใช้เป็นชั่วโมงหา เหลือหลักนาที (ข้ออ้างของผู้พูด)
  • ฟีเจอร์องค์กร: Windows support ที่ดีขึ้น, wizard deploy GCP + AWS, native binaries

สิ่งที่นำไปทำต่อ

  • ตั้ง remote control ให้เปิดตลอดใน settings.json แล้วลองสั่งงานจากมือถือ
  • ลอง /tui fullscreen ถ้า terminal กระพริบตอนใช้ session ยาว และตั้งเป็นค่าเริ่มต้นได้

  • ตรวจ memory ที่ Claude จดไว้ด้วย /memory เป็นระยะ
  • ลองตั้ง routine เล็ก ๆ เช่น triage issue หรือรีวิว PR ผ่าน GitHub event แล้วค่อยขยาย
